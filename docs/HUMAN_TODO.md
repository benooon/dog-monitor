# Things only the owner can do

Agents add items here when they are blocked. The owner checks items off.

- [ ] **Apple Developer Program** ($99/year), needed for TestFlight, push notifications and Sign in with Apple on a real device.
- [ ] **App Store Connect API key**: create it under Users and Access → Integrations → Keys (App Manager role). Add GitHub repo secrets `ASC_KEY_ID`, `ASC_ISSUER_ID` and `ASC_KEY_P8` (the .p8 contents), plus `APPLE_TEAM_ID`. Then remove `[blocked]` from the TestFlight task in BACKLOG.md.
- [ ] Create the app record in App Store Connect with bundle id `com.benooon.dogmonitor`.
- [ ] **APNs key** (.p8, Keys → Apple Push Notifications service). Set it as Railway env vars `APNS_KEY_ID`, `APNS_TEAM_ID` and `APNS_KEY_P8`.
- [ ] **LiveKit Cloud** project (free tier is fine to start). Set Railway env vars `LIVEKIT_URL`, `LIVEKIT_API_KEY` and `LIVEKIT_API_SECRET`.
- [ ] **Railway**: new project → deploy from GitHub repo `benooon/dog-monitor`, root directory `backend`, add the PostgreSQL plugin, set the env vars from `backend/.env.example`. Railway then redeploys automatically on every push to main.
- [ ] **Cloudflare R2** (or another S3-compatible bucket) for clips. Create a bucket and an API token with object read/write, then set `S3_ENDPOINT` (https://<account>.r2.cloudflarestorage.com), `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY` on Railway (`S3_REGION=auto`). Without them, events still work but without clips/snapshots.
- [ ] **GitHub Actions minutes:** macOS runners cost 10x minutes on private repos (the free plan has 2,000 min/month, which is about 200 macOS minutes). Either make the repo public (Actions are free) or add a payment method / spending limit.
- [ ] **Railway backend env**: besides `DATABASE_URL`, set `JWT_SECRET` (`openssl rand -hex 32`) and `APPLE_AUDIENCES=com.benooon.dogmonitor`. Then send agents the public Railway URL (or put it in `ios/project.yml` → `API_BASE_URL`), which currently defaults to `http://localhost:3000`.
- [ ] Enable the **Sign in with Apple** capability on the App ID `com.benooon.dogmonitor` (the app already declares the entitlement).
- [ ] Enable the **Push Notifications** and **Time Sensitive Notifications** capabilities on the App ID `com.benooon.dogmonitor` (the app declares `aps-environment` and the time-sensitive entitlement). Use `APNS_ENV=sandbox` on Railway for Xcode builds and `production` for TestFlight.
- [ ] **Invite links (Universal Links):** once the Railway URL exists, set `API_BASE_URL` (https) and `APP_LINK_HOST` (just the host, e.g. `dog-monitor-production.up.railway.app`) in `ios/project.yml`, enable **Associated Domains** on the App ID `com.benooon.dogmonitor`, and set `APPLE_TEAM_ID` on Railway (falls back to `APNS_TEAM_ID`). Until then "Share invite link" stays hidden and family members join with the 6-digit code.
- [ ] **GitHub Actions minutes (update 15:50 UTC):** Actions ran again from ~14:50 (run #132 fully green, iOS included), but in run #137 (15:00) the macOS job never got a runner and was dropped after 15 min while the Linux jobs passed. That looks like the macOS minutes running out again. Please check Settings → Billing → Actions usage; making the repo public or raising the spending limit fixes it for good.
- [ ] **Premium subscription (App Store Connect):** create a subscription group with auto-renewable products `com.benooon.dogmonitor.premium.monthly` and `com.benooon.dogmonitor.premium.yearly` (or set `APP_STORE_PRODUCT_IDS` on Railway to your ids), and sign the Paid Applications agreement. Please also check that `APPLE_ROOT_CA_G3_SHA256` in `backend/src/billing/app-store.ts` matches the SHA-256 fingerprint of "Apple Root CA - G3" on apple.com/certificateauthority (the agent sandbox could not download it). If it does not match, set `APPLE_ROOT_CA_SHA256` on Railway; until then purchases are rejected, not wrongly accepted. Turn on `ENFORCE_PLAN_LIMITS=true` only after the app sells premium. In App Store Connect → App Information → App Store Server Notifications, set both the production and sandbox URL to `https://<railway host>/app-store/notifications` (Version 2).
- [ ] **App Groups (dog status widget):** register the app group `group.com.benooon.dogmonitor` in the Apple Developer portal and enable the App Groups capability with it on both `com.benooon.dogmonitor` and `com.benooon.dogmonitor.Widgets` (the widget extension). Also enable Push Notifications on the app ID if not done (Live Activities use the same APNs key). Until the group exists the home screen widget only shows "Open Dog Monitor to see your dog here."
